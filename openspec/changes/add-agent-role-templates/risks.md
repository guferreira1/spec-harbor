# Risks: Add Agent Role Templates

## Too many roles too early

Role templates may feel like overhead for small changes.

Mitigation:

- Recommend the full flow for larger changes.
- Recommend Spec Author, Implementer, and Change Reviewer for small changes.

## Prompt drift

Templates may become inconsistent with architecture rules over time.

Mitigation:

- Keep templates short.
- Make templates reference `AGENTS.md` and the architecture spec instead of duplicating all rules.
