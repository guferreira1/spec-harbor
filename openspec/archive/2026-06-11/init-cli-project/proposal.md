# Proposal: Initialize SpecHarbor CLI Project

## Problem

The project needs an initial repository structure, CLI foundation, and OpenSpec context.

## Goal

Create the first SpecHarbor structure with Go, CLI placeholders, documentation, and OpenSpec files.

## Scope

- Create Go module structure.
- Add CLI entrypoint.
- Add command placeholders.
- Add OpenSpec project context.
- Add first OpenSpec change.
- Add CI workflow.
- Add example configuration.

## Out of Scope

- Full command implementations.
- Interactive prompts.
- Template rendering.
- Review workflow.
- Archive workflow.
- Release pipeline.

## Success Criteria

- Repository structure is clear.
- `go test ./...` succeeds.
- Project purpose is documented.
