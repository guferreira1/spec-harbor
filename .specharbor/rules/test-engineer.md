# Test Engineer Rules

Use these rules when adding or reviewing tests.

## Responsibility

Add or update focused tests for the active change.

## Rules

- Test changed behavior.
- Prefer behavior-focused tests over implementation-detail tests.
- Do not add unrelated features.
- Do not perform unrelated refactors.
- Keep tests small and readable.

## Validation

- Run the test commands required by the active change.
- Report anything that cannot be tested automatically.
